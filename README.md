# Júlia Silvestroni

Site da nutricionista Júlia Silvestroni, desenvolvido com React, TypeScript, TanStack Start e Tailwind CSS.

## Desenvolvimento

Requer Bun.

```sh
bun install
bun run dev
```

- `bun run build`: gera o build de produção em `.output` (destino atual: Cloudflare).
- `bun run test`: executa os testes.
- `bun run lint`: verifica o código.

Textos e contatos ficam em `src/content/site.ts`, as páginas em `src/routes/` e os arquivos da marca em `public/brand/`.
