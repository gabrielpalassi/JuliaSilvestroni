# Capas de destaques

Os quatro ícones do conjunto oliva, preservados em quatro cores de fundo. Traço creme #FAF7EF em todas as versões.

| Variação            | Fundo   |
| ------------------- | ------- |
| 01 · Oliva original | #3F4B33 |
| 02 · Oliva médio    | #515D40 |
| 03 · Musgo          | #5E704C |
| 04 · Sálvia         | #78866D |

São 16 capas, para Pacientes, Receitas, Atendimentos e Parcerias. Use os PNGs de 1080 × 1080 no Instagram. Os SVGs são editáveis, e os ícones ficam centralizados para o recorte circular.

- `capas-verdes-png.zip`: todos os PNGs.

Os arquivos seguem o padrão `destaque-numero-cor`.
